Importer des témoignages

1. Va sur Wyldde et ouvre le profil d'un de tes contacts.
2. Clique sur son compteur de témoignages (ex: "Témoignages (4)").
3. Dans DevTools → Network → filtre test → clique sur testimonies?nocache=...
4. Onglet Response → Ctrl+A → Ctrl+C → colle ci-dessous.
5. Sélectionne à qui appartiennent ces témoignages et clique Importer.
